# 🎤 Overground Festival 2027

Une Landing Page moderne et interactive pour un festival de Rap & Street Culture, construite avec **Vue.js 3** et **Vite**.

## ✨ Fonctionnalités

- **Hero Section immersive** avec un titre percutant et un design sombre/néon.
- **Compte à rebours dynamique** en temps réel jusqu'au jour J.
- **Line-up interactif** avec un système de filtres par jour (Jour 1 / Jour 2).
- **Billetterie dynamique** avec sélection des pass, calcul du montant total en temps réel et panier flottant.
- **Section FAQ / Infos pratiques** avec un accordéon déroulant.
- **Footer complet** avec formulaire d'abonnement à la newsletter.

## 🛠️ Stack Technique

- **Framework :** Vue.js 3 (Composition API avec `<script setup>`)
- **Outil de build :** Vite
- **Style :** CSS natif (Design System sombre / néon, Flexbox, Grid, Glassmorphism)
